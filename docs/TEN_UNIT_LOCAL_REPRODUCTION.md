# Running the original ESWA ten-unit source with measured inputs

The repository contains the original implementation of the estimators, 18 selected scan-level indicators, composite SQS, retrospective warning analysis and supplementary analysis drivers. **The approved reference outputs are archived and not rebuilt by the input-preparation command.**

## Available measurement data

- U01–U03: transformed subsets of UJIIndoorLoc, with source attribution and CC BY 4.0 reuse notice in `docs/UJI_DATA_ATTRIBUTION.md`. The `data/empirical/U0*.csv.gz` files include observed train and test RSS; `split=train` rows are the radio map.
- U09: observed HK U09 with `AP1`, ... identifiers and relative metre coordinates, already published at `data/empirical/hk_u09_ap_relative.csv.gz`. Ordered input for the original results is separately available in `data/radio_maps/hk_u09_train.csv.gz` and `data/empirical/hk_u09_test_ordered.csv.gz`.
- U04–U08 and U10: original measurement sources at the dataset publisher pages; the curated, identifier-relabeled combined unit tables are supplied only in the local full research bundle until applicable redistribution conditions have been checked. They are not generated by a synthetic fixture.

## Reproducing with all ten authorized input tables

From the **full local research bundle** (or a GitHub clone with ten compatible authorized files copied into an ignored local `LOCAL_MEASURED_UNITS/` directory):

```bash
python -m pip install -e ".[dev]"
python scripts/stage_existing_units.py --input-dir ../LOCAL_MEASURED_UNITS
python -m wifi_integrity benchmark-native --units U10 --estimators knn,wknn --output-name u10_native.csv.gz
python scripts/reproduce_release.py --mode reference
python scripts/verify_existing_research_assets.py
```

- `stage_existing_units.py` validates original 54,520 training and 13,629 test scan counts; produces `data/processed/units/Uxx/radio_map_matrices.npz` and AP vocabularies using **existing** repository harmonization functions. No fitting or experimental result substitution occurs at this stage.
- `benchmark-native` runs source estimators with a fresh fit, saving predictions and numerical summaries under `results/` (locally ignored). Other estimator IDs in the existing code are `random_forest`, `extra_trees`, `hgb`, `catboost`, `transformer_ap`, `residual_cnn`. Install optional backend dependencies for the latter three. Fresh estimators are **not guaranteed to match** the historically approved model fit and tuning; the original stored results remain the reference.
- `reproduce_release.py --mode reference` replays approved stored predictions and the numerical indicator/diagnostic analysis. It does **not** retrain all eight estimators. The appropriate input reference data live in `reference/approved/legacy_canonical/` in the full local source package.
- The source code uses the original saved estimator configurations as appropriate. To make a full comparison to the paper, inspect `config/estimators.yaml` and the source’s native estimator parameter derivation, then compare unit/condition outputs to the approved references, rather than claiming equality without testing.
