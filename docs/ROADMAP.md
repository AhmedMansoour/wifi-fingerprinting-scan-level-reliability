# Availability and next stages

| Stage | Current status | Next evidence needed |
|---|---|---|
| Runnable Python package | Included with demo, eight native adapters, and unit tests | Extend checks to additional supported environments |
| Reference reproducibility | Included numerical checks, ablations, and unit-cluster intervals | Independently reproduce full historical training where source data are authorized |
| HK public data | Relative locations and opaque AP tokens included | Maintain privacy review for future additions |
| Android source | Included with empty database initialization and local import | Validate on additional devices and authorized radio maps |
| Prospective warning evaluation | Frozen-profile tooling and protocol included | Independent calibration/evaluation cohorts and reported effectiveness |
| Extended raw-data analyses | Original numerical drivers included with prerequisites | Acquire authorized third-party radio maps and run the full experiments |

Future data or result additions must preserve the publication boundaries in [DATA_AND_PRIVACY.md](DATA_AND_PRIVACY.md). The current package does not include the manuscript, private floor maps, or private identifier mappings.
