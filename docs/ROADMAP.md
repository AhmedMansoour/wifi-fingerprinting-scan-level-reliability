# Availability and development roadmap

[Home](../README.md) · [Reproducibility](REPRODUCIBILITY.md)

## Current public state

The repository provides a research overview, an indicator guide, execution-scope documentation, and an Android implementation guide. The Python and Android software directories remain placeholders while the source packages are prepared.

## Planned progression

| Stage | Deliverable | Completion evidence |
| --- | --- | --- |
| 1. Source and synthetic example | Curated Python source, minimal dependencies, and generated-data demo | Fresh installation and data-free tests succeed |
| 2. Android source | Java project, empty-database initialization, and radio-map import guide | Gradle build, empty-state startup, and authorized map import succeed |
| 3. Reference reproduction | A documented, separately approved input bundle and replay instructions | Scan identifiers, counts, and reference-summary checks agree |
| 4. Native evaluation | Explicit supported-estimator coverage and reconciled diagnostic computations | Differences from stored references are explained and measured |
| 5. Research interface | Result explorer linked to validated outputs | Every displayed result has traceable inputs and working artifact links |

The manuscript title and under-review status are retained. Author information, licensing, archival identifiers, citation metadata, and automated publication are deferred to later decisions.

Feedback can be shared through [Issues](https://github.com/AhmedMansoour/wifi-fingerprinting-scan-level-reliability/issues). Useful reports identify the intended task, component, version, environment, and minimal steps needed to reproduce an issue.
