# Data and privacy boundaries

`examples/synthetic_combined/` contains **fully fabricated** RSS, access-point labels, 2D metric positions, and categorical floors. Ten registry slot names and original sample counts are present for software compatibility; **no real location or RSS values were used to generate the fixture**. The relative positions have no coordinate origin and are not derived from HK buildings.

This public candidate includes no real HK AP/BSSID identifiers, original HK GPS/cartesian coordinates, real floor-plan imagery, reconstructed map vectors, populated site databases, or empirical per-scan results. Program code may support real inputs supplied by authorized researchers in private local folders.

A private research archive with true derived fingerprint scans exists separately and **must not be committed**. Even removing device identifiers and translating coordinates cannot by itself guarantee privacy or authorize third-party dataset redistribution. Do not publish that private archive, scans, map representations, or site metadata without a new documented approval.
