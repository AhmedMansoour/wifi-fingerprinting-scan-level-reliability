IMPORTANT DISTINCTIONS

What can you conclude?

A radio-map candidate plot describes evidence geometry. The displayed centroid is a diagnostic candidate-set location, not one of the paper’s trained estimator outputs. A true reference position is shown only when explicitly requested.

Three different quantities

SQS: normalized support. Positioning error: requires a prediction and known ground truth. Gross-error warning: requires a calibrated decision rule and evaluation protocol.
