# Toward Integrity-Aware Wi-Fi Fingerprinting: Scan-Level Reliability and Gross-Error Diagnosis Across Datasets and Estimators

This repository will host the Python analysis pipeline and Android implementation associated with the paper.

**Code and reproducibility materials are being prepared for the public release.**

## Preliminary repository structure

| Folder | Planned contents |
| --- | --- |
| `src/` | Python analysis pipeline |
| `scripts/` | Analysis and reproducibility scripts |
| `android/` | Android implementation |
| `config/` | Configuration files |
| `examples/` | Usage examples |
| `docs/` | Documentation |
| `results/` | Generated analysis outputs |
| `metadata/` | Experiment and dataset metadata |

Each folder currently contains only a `.gitkeep` placeholder.
